# Dar Zitouna – Site d'un restaurant tunisien

Mini-projet « Développement Web côté client » (TI1, semestre 1, A.U. 2026-2027).

## Thème
Site vitrine d'un restaurant : présentation, menu filtrable, réservation et contact.

## Technologies
- HTML5 sémantique (header, nav, main, section, article, footer)
- CSS3 : fichier externe, variables CSS, Flexbox/Grid, media queries (mobile-first)
- JavaScript : DOM, événements, validation de formulaires (aucune bibliothèque)

## Fonctionnalités JavaScript
1. Menu burger responsive
2. Mode clair / sombre mémorisé (localStorage)
3. Filtre du menu par catégorie + recherche
4. Validation des formulaires (champs obligatoires, e-mail, téléphone, date, message d'erreur clair)
5. Compteurs animés, statut ouvert/fermé, estimation du budget

## Arborescence
```
index.html
pages/   menu.html, reservation.html, contact.html
css/     style.css
js/      main.js, menu.js, form.js
images/  hero.svg
```

## Ouvrir le site
Ouvrir `index.html` dans un navigateur (aucune installation nécessaire).
